# 截止日历与 iCalendar 导出

## 使用流程

导航和首页周任务区可进入“日历”。支持周 / 月切换、前后翻页、回到今天、日期选择、课程与状态筛选。默认展示待办与进行中的任务；“全部”不含归档，也可明确选择已完成、已取消或已归档。

日历以任务截止时刻归日，按浏览器本地时区展示；时区名称显示在页面。月历从周一开始、固定六行；相邻月份日期灰显，点击会切换到对应月份，不把未加载的邻月任务当作当前月数据。周视图显示周一至周日，窄屏改为按日纵向排列。

点击日期，在下方查看当天完整任务；点击任务进入现有详情。日历参数保存在地址栏，从任务详情通过浏览器返回时保留日期、视图和筛选。当天任务可使用现有完成 / 撤销操作，日历按最新任务重新读取。任务延期或取消后，重新进入 / 刷新也使用最新截止时间和状态；页面重新可见时重新读取。

没有截止时间的任务单独列在“还没定截止时间”，按当前课程 / 状态筛选，但不受日期范围限制。它们不会被任意安排到某天，也不会被导出。

## 导出范围与语义

“导出当前视图 .ics”下载当前整月或整周、当前课程与状态筛选下，有明确截止时间的任务。月视图不包含灰色邻月日期，周视图可以跨月。文件是导出时的数据快照，不是自动订阅或双向同步。后续修改需重新导出；重复导入是否覆盖取决于日历客户端，不能保证所有客户端自动去重。

文件包含任务标题、课程、截止时刻、状态、任务内容、提交信息、地点和备注。不会额外导出关联原文列表、消息来源账户或字段审核记录。文件保存在本机，由用户自行选择是否导入其他日历。

每项任务用一个 VEVENT 标记截止时间，DTSTART 使用 UTC；不补造事件起止时长、课程上课时间或提醒。按 RFC 5545，DATE-TIME 的 DTSTART 无 DTEND 时表示同一时刻结束。TRANSP:TRANSPARENT 不占用忙碌时段，没有 VALARM 或邀请收件人。

UID 使用稳定任务 ID；SEQUENCE 使用任务版本，CREATED / LAST-MODIFIED 使用任务时间。取消任务使用 STATUS:CANCELLED；完成 / 归档通过标题前缀与描述明确标注，VEVENT 不使用非法的 COMPLETED 状态。已完成 / 取消 / 归档只有显式包含在筛选中才导出。

文本进行反斜线、逗号、分号、换行转义，去掉不合法控制字符。输出 UTF-8、CRLF，物理行按最多 75 字节折行且不拆开 UTF-8 字符。下载使用固定安全文件名与 no-store 响应；空范围返回明确提示，不编造事件。

规范参考：[RFC 5545 §3.1 与 §3.6.1](https://www.rfc-editor.org/rfc/rfc5545.html)。本项目用独立 icalendar 解析器做往返验证，尚未在 Apple / Google / Outlook 日历中逐一实机导入验收。

## 接口与数据边界

- GET /api/calendar：start、end（结束日期不含）、timezone、status、course；返回日期范围、时区、有日期任务和无日期任务。
- GET /api/calendar/export.ics：同一组参数；返回 text/calendar 附件，只含有日期任务。

日期范围限 1–62 天，课程长度不超过 100。无效日期、时区、状态或范围返回 422。时区本地午夜边界转换成 UTC 后查询，因此夏令时日期不强行当作固定 24 小时。页面按同一浏览器时区归日；改变系统时区后建议刷新页面。

接口只读，不新增数据库表、不修改任务、来源、事件或提醒。前端通过请求修订号避免旧筛选响应覆盖新结果。导出单独处理文件响应、超时和错误；导出过程中更换筛选时，完成提示仍注明实际导出范围。

前端日期工具用本地中午作为日期锚点，避免加减天数时跨夏令时偏移；月份切换会夹取到有效月底，例如 1 月 31 日切到 2 月 28 / 29 日。日期参数验证实际日历日期，不接受 2 月 30 日。

## 验证与后续范围

后端测试覆盖范围边界、UTC 与本地日期、夏令时、筛选、无日期任务、只读导出、稳定 UID / 递增版本、中文与 emoji 折行、文本注入转义、状态语义，以及截止时间 / 取消审核后的视图变化。icalendar 仅作为开发测试依赖。

前端使用 Node 内置测试运行器，在上海、纽约、UTC 三种时区验证月底、闰年、周一开始、跨年与夏令时日期计算，已加入本地检查脚本和 CI 配置。

尚未实现日历自动同步 / 订阅、双向编辑、拖拽改时间、课程课表、重复事件和在日历客户端中的自动提醒。
