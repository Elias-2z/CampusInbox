# 本地／API 模型使用说明

适用于仓库根目录的 FastAPI + Vue 应用，不适用于独立 `local-assistant/`。

## 使用

1. 打开「设置 → 通知识别」。本地模式保留原 Ollama 配置，可测试连接并读取已安装模型。
2. 选择「API 模型」，填写服务商给出的 HTTPS 基础地址与实际 Model ID。兼容接口为 `POST <基础地址>/chat/completions`；不要重复填写后半段。部分服务要求基础地址含 `/v1`，以该服务文档为准。本机测试服务可用回环 HTTP。
3. 输入 API Key，选择是否启用 API 兜底，调整超时与每日调用次数上限。默认请求 JSON 输出；服务不支持时可在输出选项关闭，但仍须返回符合字段结构的 JSON 对象。
4. 阅读并确认数据发送与可能费用，点击「测试 API（合成文本）」。测试只发送固定虚构句子，不读取已有通知；测试也计入调用次数，并可能消耗服务商额度。
5. 测试通过后保存。保存后，手动导入的通知及其重新识别使用所选模式。QQ、学习通自动采集、旧版迁移记录及课务助手继续使用本地模型配置。

切换回本地时保留两套配置。密钥留空表示保留同一基础地址的旧密钥；换地址后需输入该地址的密钥。不会将旧地址的密钥发送到新地址。更换地址或模型需要重新确认数据发送。测试不会保存新密钥，也不会自动启用 API。

## 数据与密钥

- 配置和调用次数保存在本机 SQLite；密钥不写入数据库、浏览器 localStorage、Git 或普通接口响应。
- macOS 使用钥匙串；Windows 使用当前用户凭据管理器（代码已实现，尚待真实 Windows 验收）。Linux 当前不提供明文回退，安全存储未配置时无法保存密钥。
- API 推理会向服务商发送手动导入的通知原文、实际发送时间和时区。原文可能包含个人信息。服务商留存与计费规则请查阅对应服务条款。
- 默认沿用已有本地设置，不默认启用 API；本地失败不自动转云端，API 失败不自动转其他服务。规则结果和原文仍保存在本机供审核，模型不能直接创建或修改任务。
- API Key 不要发到聊天、截图或提交 Git。数据库迁移不包含系统密钥；迁移机器或数据库路径后需要重新配置密钥。密钥撤销在服务商后台完成。

## 额度与兼容性

每日上限按 UTC 日期和基础地址统计本机请求尝试；测试、失败请求均计入，重启不会清零。不自动重试，也不跟随 HTTP 重定向。该上限不是金额预算，其他软件调用与服务商计费不受它控制。网络连接不使用系统代理环境变量。

已验证模拟的兼容响应、鉴权失败、超时／格式错误、调用上限、并发限额、配置冲突和本地切换。没有使用真实用户 API Key 联调；不同服务商与模型对 JSON、输出 token 参数的支持可能不同，需通过设置中的测试验收。

## 开发接口

- `GET /api/settings/inference`：模式、两套配置、配置版本、密钥是否存在（不含密钥）、调用次数。
- `PUT /api/settings/inference`：携带读取的 revision 保存；旧版本返回 409，避免覆盖他人修改。密钥仅作为写入字段。
- `POST /api/settings/inference/probe`：按请求配置测试；不保存、不切换模式。
- 原 `/api/settings/model` 保留为本地配置兼容接口，不改变当前模式。

测试注入模拟网络和凭据存储，使用临时数据库，不发送真实通知。
