# Mac 学习通接入

适用于主应用（8000 / 5173），继续使用原学习通采集、去重和人工审核流程。不会读取浏览器个人配置，也不会自动提交作业、考试或签到。

## 安装与登录

1. 安装 Python 3.11、uv、Node.js 24 和 Google Chrome。已有 Chrome 时不用另装浏览器。采集器也支持 Mac 上的 Edge，或已安装的 Playwright Chromium。
2. 在项目根目录运行 `uv run --python 3.11 scripts/setup.py` 安装锁定依赖。已有开发环境只需 `uv sync --directory backend --locked` 和在 `integrations/chaoxing/desktop-sync` 执行 `npm ci`。
3. 启动主应用，进入「设置 → 数据源连接 → 学习通」，选择「扫码连接 / 恢复」，用手机学习通扫码并确认。必要时可以打开学习通官方窗口。密码和验证码无需交给项目。
4. 登录后会读取近 30 天的课程通知以及作业考试目录；聊天采集关闭，消息先进入收件箱，仍须人工核对。课程通知和作业考试分别展示检查状态；连接正常不等于全部内容已读完。

若没有 Chrome / Edge，可在 `integrations/chaoxing/desktop-sync` 执行 `npx playwright install chromium`。后台进程不继承终端 PATH 时，会检查常见 Homebrew Node 安装位置；其他安装方式需要在后台服务的 PATH 中包含 Node。

## 本地登录保存

- Mac 使用 AES-256-GCM 加密浏览器登录状态，文件位于数据库目录下的 `chaoxing/session.bin`，权限为仅当前用户读写；加密密钥存入当前用户的 macOS 钥匙串，以数据目录隔离。
- 业务数据库、普通配置、浏览器存储和 Git 不保存明文登录状态；Cookie 不通过命令行参数或日志输出。采集器的独立浏览器上下文仅在运行时持有登录状态。
- 启用采集后重启后台服务，会尝试读取本机加密状态并恢复。Mac 钥匙串被锁、密钥丢失、状态损坏或学习通会话过期时需要重新扫码，不承诺永久登录。
- 页面分别展示登录文件是否保存及安全存储错误，避免在线状态掩盖保存失败。断开连接会关闭采集、删除保存的登录文件并更换本地来源账号标识；已收通知和任务保留。
- Windows 继续使用原 DPAPI 格式，已有 Windows 登录文件不迁移、不改写；两个系统的登录状态不互通。Mac 的备份迁移到其他目录或机器后需要重新登录。

## 通知和作业

已兼容 `mooc2-ans.chaoxing.com` 与 `mooc1-1.chaoxing.com` 的官方课程目录入口。课程按批检查，不会一打开就读完全部课程；可在连接页查看栏目回执和请求优先检查。

课程通知和作业中心分别显示覆盖情况，聊天显示不采集。详情不支持、附件缺失、发布时间未知或平台权限限制均保留待核对提示。重试已保存但处理未完成的消息会复用原建议，不重复创建通知或任务。

自动采集沿用本地规则／Ollama，不自动使用云端模型 API。图片／PDF 的 Windows 本机 OCR 不随此次适配移植到 Mac；Mac 可保留原件人工核对，手动上传后使用已配置且明确同意的 MinerU 解析。

## 验证

2026-11-05 已在当前 Mac 验证真实扫码登录、课程通知进入主收件箱、作业考试目录发现及部分记录接收，后台服务重启后无需再次扫码即可恢复。钥匙串加密和新解释器解密也已使用合成会话验证，合成钥匙串条目已清理。

这不是全量采集准确率或长期在线验收。当前账号有多个课程及不同页面模板，部分来源仍可能显示覆盖不完整。日志和公开文档不记录账号、课程名称、Cookie 或二维码。


## 当前采集范围（2026-11-05）

按用户选择，聊天不采集，课程通知仅处理最近 30 天，作业考试仍分批检查。采集器先按列表发布时间筛选，再按详情发布时间核对；后端和网页组件入口也执行同一范围检查。发布时间未知的课程通知仅进入单独的时间待核对队列，不用扫描时间冒充发布时间。

首次应用范围时，先前收进来的聊天和较早课程通知会移到历史归档，通知原文仍保留。已确认的任务和已有拆分审核进度不改动；新消息不在范围内时不会再进入识别或下载附件。
