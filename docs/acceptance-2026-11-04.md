## 独立 Windows 助手的附加检查

`local-assistant/` 与主应用的 API、数据库和任务相互独立。本机补跑：

```bash
../backend/.venv/bin/python -B -m unittest discover -s tests
```

共运行 687 项，668 项通过、2 项失败、15 项错误、2 项跳过。未把这次结果记为独立 Windows 版验收通过：

- Windows 启动器、桌面程序相关测试依赖 PowerShell、`.cmd` 与 Windows 环境，Mac 无法执行。
- 会话持久化与微信推送使用 Windows DPAPI；Mac 缺少该加密能力，造成保存会话断言失败和相关错误。
- 当前主应用 Python 环境未安装独立助手 Web Push 所需 `cryptography` 等专用依赖；单项复查确认了依赖缺失。

没有为消除这些失败而替换 DPAPI 或关闭断言，也没有改动同学的 Windows 代码。应由 Windows 同学在其项目环境运行 `local-assistant/scripts/run-tests.ps1`，再做桌面程序与真实学习通流程验收。

2. 当前 Mac 后端未配置 MinerU Token，图片／PDF 真实解析需要先补充本机配置。本轮验证上传到审核的流程与故障回归；真实 MinerU、复杂截图／扫描件效果需额外验收，可参照此前真实 PNG／PDF 验证记录。
3. QQ 本轮检查在线和核心回归；现场演示前可由群里另一位成员发送合成通知，核对课程来源、待审核状态和无重复任务。
4. 学习通属于独立 Windows 助手的接入路径，尚未与主应用任务库打通；主应用微信 Connector 仍未实现。
5. 系统推送、备份恢复、自动日历同步等未实现能力不纳入本轮通过结论。
