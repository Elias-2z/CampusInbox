# 站内截止提醒

## 用户体验

导航新增“提醒”与未读数量，首页展示未读提醒概览。提醒页按未读、稍后提醒、已读、全部筛选。即将截止和逾期分开显示，可进入任务详情、标为已读、稍后提醒或恢复未读。

设置页可开启 / 关闭站内提醒，选择提前 15 分钟、1 / 3 / 6 小时、1 / 2 天或 1 周，以及是否显示逾期提醒。默认开启、提前一天、显示逾期。API 允许 5–10080 分钟的提前窗口；界面对已有自定义值可正确回显。稍后提醒支持 15 / 30 / 60 / 120 分钟。

页面可见时约每 30 秒刷新提醒，回到页面 / 窗口时重新检查，任务操作后也重新检查。主动开启浏览器通知后，页面在后台时也会尝试检查，浏览器节能策略可能延迟检查。提醒请求失败时单独提示，保留上次结果，不阻断收件箱或任务使用。过期请求响应不会覆盖较新结果。

设置中可主动开启浏览器通知并授权；开启时已有未读提醒不会集中弹出，新出现的未读提醒可弹出系统通知，稍后提醒到期后可以再次提醒。该开关和已通知记录保存在当前浏览器中。关闭页面、服务停机或电脑休眠时不会触发通知；无后台常驻保证，不能视为闹钟。

## 提醒规则

只针对已确认且有截止日期或时间的待办、进行中和已做完任务；未确认通知、拆分草稿、没有截止时间的任务不提醒，已提交、已完成、已取消或归档任务不出现在列表。只有日期的任务在该日期结束后视为逾期。

- 即将截止：0 < due_at - 当前时间 <= 提前窗口，包含窗口边界。
- 逾期：due_at <= 当前时间；可以独立关闭。
- 时间与比较均使用服务端带时区 UTC；界面显示浏览器本地时间。

同一提醒由 task_id + UTC 截止时间点 + upcoming / overdue 阶段确定，哈希作为稳定 ID。不同时间格式但相同时间点不会创建另一提醒。标题、备注等编辑不改变该 ID，列表使用最新任务信息。

标已读不会完成或编辑任务。稍后到期后重新未读；稍后间隔以服务端时间计算，不会因为重试延长。即将截止的已读 / 稍后状态不会压制到期后的逾期提醒，逾期是新阶段。

延期或合并改变截止时间后，旧提醒立即不再符合条件，按新截止时间重新计算。旧提醒操作返回 409 并触发前端刷新。恢复原截止时间且阶段相同，则恢复该提醒此前的处理状态；如果已进入逾期阶段，则使用逾期阶段的独立状态。

关闭提醒或缩短窗口不删除处理记录；之后重新符合条件时保留已读 / 稍后状态。完成、取消、归档及其撤销也按最新任务状态判断。

## 持久化与一致性

新增 ReminderSettings 和 ReminderState 两张独立表。通过 create_all 增量初始化，保留已有业务表和模型配置。升级前已创建 SQLite 一致性备份。

GET 列表实时从当前任务计算，不写任务或提醒记录；只有用户处理提醒时才持久化对应状态。ReminderState 保存任务、截止时间、阶段、已读、读取时间、稍后截止、版本与更新时间。提醒处理不增加 TaskEvent 或修改 Task.version。

处理请求携带 expected_version，写事务中重新检查提醒仍有效及版本。重复标已读 / 恢复未读是幂等的；并发或重试稍后提醒使用旧版本会返回 409，不默默顺延。状态更新、返回快照在同一写事务内完成。已读 / 稍后和配置支持刷新、重启恢复。

任务完成 / 取消等不需要同步清理排队任务，因没有独立后台调度队列；下次检查直接排除不再有效的提醒。旧处理状态保留但不显示，便于撤销原任务变更后恢复一致行为。

## API

- GET /api/reminders：config、items、evaluated_at。items 返回最新 TaskRead、阶段、提醒状态、截止时间、已读 / 稍后时间与版本。
- GET /api/settings/reminders；PUT /api/settings/reminders：enabled、lead_minutes、overdue_enabled。
- POST /api/reminders/{id}/read、snooze、restore：expected_version，snooze_minutes 默认 30，仅接受 15 / 30 / 60 / 120。

create_app 提供内部 reminder_clock 注入，测试可确定时间边界与到期行为；没有对外修改时钟或模拟提醒的接口。

## 快速测试

1. 手动创建任务，截止时间设为未来一小时，保持待办。
2. 进入“提醒”，查看即将截止卡片，标为已读后未读数量减少，任务仍是待办。
3. 在已读页恢复未读，再选择稍后提醒；刷新后到“稍后提醒”页核对恢复时间。
4. 把任务截止时间改到三天后，默认一天窗口内不再显示旧提醒。
5. 把时间改回未来一小时，完成任务后提醒消失；撤销完成后恢复。
6. 设置页改为提前一小时，或关闭站内提醒，检查列表变化。
